# Device identification

Reference platform: **Verdant Trace VT02 / Topin ZX909**, firmware `ZX909_EU_V1.3.7_2025-11-17_09-43-24`.

> **Use at your own risk.** Similar product names or enclosures do not prove identical hardware or firmware.

The repository uses **ZX909 Family** as practical project scope, not as a claim that Topin officially defines every related product as one family.

Useful identification evidence includes firmware strings, protocol traffic, modem information, PCB markings and reproducible command behaviour.

**Confirmed:** findings in this project were reproduced on the tested Verdant Trace VT02 devices.  
**Not established:** every VT02, ZX909 or reseller variant contains identical hardware.

Public examples must omit full IMEIs, ICCIDs and other unique production identifiers.
